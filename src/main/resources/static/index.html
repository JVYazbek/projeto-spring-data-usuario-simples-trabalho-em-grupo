Objetivo do projeto

Mostrar o mínimo necessário para o Hibernate criar a tabela.

O foco é provar didaticamente que a combinação de Entity, JPA, Hibernate e configuração da aplicação já é suficiente para gerar a estrutura no banco H2.

🏷️

@Entity

Marca a classe Java como uma entidade persistente que poderá ser mapeada para uma tabela.

🧱

Hibernate ORM

Lê as anotações da entidade e cria ou atualiza a tabela automaticamente no banco.

🗄️

H2 em memória

Cria um banco temporário chamado usuariosdb, ideal para estudo e testes rápidos.

🧪

H2 Console

Permite visualizar tabelas, colunas e consultas SQL diretamente pelo navegador.

Arquitetura simples

Estrutura enxuta para enxergar o essencial.

O projeto contém apenas a aplicação principal e a entidade de domínio, mantendo Repository, Service e Controller fora de propósito nesta etapa.

Estrutura do projeto 
src/main/java/com/exemplo/usuariosimples
 ├── UsuarioSimplesApplication.java
 └── domain
     └── Usuario.java
🎯

Ideia central

A Repository não é responsável por criar tabela. Ela será útil depois, para manipular dados. A criação da tabela vem do mapeamento da entidade e da configuração JPA/Hibernate.

Sem Controller Sem Service Sem Repository

Classe Entity

Anotações que fazem o mapeamento.

A entidade Usuario fica no package domain e representa a tabela usuarios.

🏷️

@Entity

Informa que a classe representa uma entidade persistente.

📛

@Table(name = "usuarios")

Define explicitamente o nome da tabela que será usada no banco.

🔑

@Id

Marca o campo que representa a chave primária da tabela.

🔢

@GeneratedValue

Configura a geração automática do identificador com estratégia IDENTITY.

📏

@Column

Permite declarar regras simples de coluna, como nome, tamanho ou obrigatoriedade.

🧠

Hibernate

Usa essas informações para montar o DDL da tabela no banco H2.

Configuração

application.properties explicado por blocos.

Porta da aplicação
server.port=8081

Sobe a aplicação na porta 8081.

Datasource H2
spring.datasource.url=jdbc:h2:mem:usuariosdb
spring.datasource.driverClassName=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=

Cria um banco H2 em memória chamado usuariosdb, com usuário sa e senha em branco.

Console no navegador
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console

Habilita o console em http://localhost:8081/h2-console.

JPA / Hibernate
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true

Cria ou atualiza a tabela com base na Entity, mostra SQL no console e formata melhor a saída.

Como executar

Passo a passo no IntelliJ ou Maven.

Abrir o projeto

No IntelliJ, acesse File > Open, selecione a pasta do projeto e aguarde o Maven baixar as dependências.

Rodar a classe principal

Execute a classe UsuarioSimplesApplication para subir a aplicação Spring Boot.

Alternativa via terminal

Use o comando Maven abaixo para iniciar a aplicação pela linha de comando.

Comando Maven
mvn spring-boot:run
Teste no navegador
